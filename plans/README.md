# Planos (documentos internos de projeto)

Esta pasta guarda o **planejamento e o registro de execução** do narnia-jobs, escritos durante o desenvolvimento: viabilidade, fluxos, arquitetura, dados, wireframes, decisões do mantenedor e uma task por entregável (`tasks/`), com o registro do que foi feito em cada marco.

- São documentos de trabalho em pt-BR: podem estar desatualizados em relação ao código, e o código vence.
- Para **usar** o narnia-jobs, leia o [README](../README.md) e o [tutorial](../docs/tutorial.md).
- Para **contribuir**, leia o [CONTRIBUTING](../CONTRIBUTING.md); as tasks ajudam a entender por que algo foi feito de um jeito.

Ponto de partida: [`plan-v0/tasks/README.md`](plan-v0/tasks/README.md) (entregáveis F01 a F12, ordem e dependências).
