# Código de conduta · Code of conduct

*English below.*

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/). Em resumo: seja respeitoso, acolha quem está começando, critique ideias e não pessoas, e não tolere assédio de nenhum tipo, em issues, pull requests, discussões ou qualquer espaço do projeto.

Para relatar um comportamento inaceitável, use o relato privado do GitHub (aba **Security** › **Report a vulnerability**, indicando no título que é um caso de conduta) ou fale diretamente com o mantenedor pelo perfil do GitHub. Todo relato é tratado com sigilo.

---

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful, welcome newcomers, criticize ideas rather than people, and do not tolerate harassment of any kind in issues, pull requests, discussions or any project space. To report unacceptable behavior, use GitHub private reporting (**Security** tab › **Report a vulnerability**, stating in the title that it is a conduct report) or contact the maintainer through their GitHub profile. Every report is handled confidentially.
